# QuickArt 🎨

QuickArt is a modern web application designed for small-scale business owners to easily showcase and sell their products online through WhatsApp and social media platforms.

Business owners can create an account, add products with images, prices, and descriptions, and instantly get a shareable product link. Customers can browse products and place orders directly through WhatsApp — making online selling simple, fast, and accessible.

---

## 🚀 Features

* User authentication for business owners
* Add, edit, and manage products
* Product image uploads
* Product pricing and descriptions
* Shareable store/product links
* WhatsApp-based ordering system
* Mobile-friendly responsive UI
* Simple and clean dashboard

---

---

## 📌 How It Works

1. Business owner creates an account
2. Adds products with:

   * Product name
   * Price
   * Description
   * Images
3. QuickArt generates a shareable link
4. Owner shares the link through:

   * Instagram bio
   * WhatsApp Business
   * Social media
5. Customers browse products
6. Customers place orders through WhatsApp

QuickArt acts like a simple digital storefront for small businesses making online selling easy without needing a full ecommerce website.

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/your-username/quickart.git
```

### Navigate into the project

```bash
cd quickart
```

### Install frontend dependencies

```bash
cd frontend
npm install
```

### Install backend dependencies

```bash
cd backend
npm install
```

---

## ▶️ Running the Project

### Start Backend

```bash
npm run dev
```

### Start Frontend

```bash
npm start
```
